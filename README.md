# Ruined Client (Fabric, Minecraft 26.1.2) - made by ocxh

Client-side mod. Needs Fabric Loader 0.19.2+, Fabric API and Java 25.

- Open the menu with **Right Shift** (works on the title screen too).
- Restricted modules are locked on public servers. Only add servers you own or administer under Settings -> Server Safety.
- Settings and profiles live in `config/kelpclient/` and are saved automatically.

## Build on GitHub
1. Upload everything in this folder (the `.github` folder must keep its path).
2. Actions -> "Build mod" -> download the `ruinedclient-jar` artifact.
3. Put the jar in `mods` next to Fabric API.
